PUBBLICAZIONE:
1. Accedi a GitHub con account maxymix-hub (verifica l'esatto username).
2. Crea repository pubblico chiamato maxymix-hub.github.io SE username è esattamente maxymix-hub.
3. Carica index.html e l'intera cartella assets (non caricare solo lo ZIP).
4. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. Apri https://maxymix-hub.github.io/ una volta pubblicato.

VERIFICA GOOGLE SEARCH CONSOLE:
- Aggiungi una proprietà di tipo Prefisso URL: https://maxymix-hub.github.io/
- In Search Console scegli una modalità di verifica disponibile. Se viene fornito il meta tag HTML, incollalo nella sezione <head> di index.html dove è presente il commento 'Google Search Console'. Pubblica la modifica e clicca Verifica.
- Torna in Play Console e completa la richiesta di associazione/verifica del sito.
- Su hosting condiviso github.io alcuni metodi di verifica possono avere limiti; utilizzare la verifica con meta tag o file HTML per la proprietà URL prefix, seguendo le istruzioni correnti di Search Console.
